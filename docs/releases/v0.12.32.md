# Release Notes - v0.12.32

Stable release. Promotes the `0.12.32a3`–`0.12.32a9` alpha series to
stable — no code changes since `0.12.32a9`. See the individual alpha
release notes (`docs/releases/v0.12.32a3.md` through `v0.12.32a9.md`) and
the CHANGELOG for the full set of fixes rolled up into this release,
covering: `kindling env update`/`env bootstrap` workspace-sync and
multi-project propagation fixes, wheel version selection, Databricks
Unity Catalog Volumes support (app deploy and job cluster access mode),
keyless/append-only entity defaults, and watermarking/parallel-generation
fixes for keyless entities and first-time Delta table creation.

**Full Changelog**: https://github.com/sep/spark-kindling-framework/compare/v0.12.32a9...v0.12.32
