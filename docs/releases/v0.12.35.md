# v0.12.35 — Structured Lakeflow configuration

> Correction: this release introduced a Lakeflow-specific configuration key
> that has since been superseded. Use the canonical
> `spark.kindling.bootstrap.config_files` or
> `spark.kindling.bootstrap.artifacts_storage_path` inputs; the
> `kindling.lakeflow.config_files` key is now only a deprecated compatibility
> alias.

Lakeflow Bundles can now set `kindling.lakeflow.config_files` to a comma-separated list of deployed YAML paths. The selector loads these files before entity and pipe registration, preserving dotted IDs in `dataentities` and `dataentities-bytag` mappings. Existing flat runtime configuration takes precedence.

The default selector behavior and `EntityNameMapper` remain unchanged. Pipeline-local leaf dataset naming stays independent from fully qualified external table mappings. Invalid configuration sources produce actionable errors.

Documentation includes Bundle examples for bronze/silver telemetry and temporal events/episodes. Workspace file access on serverless Lakeflow remains unverified in a live workspace.

Validation: Gas City review approved after fixes; 2,859 unit tests passed and 2 skipped. This patch uses the fast-track wheel build and smoke-test release lane, followed by a separately dispatched full CI/CD run across all platforms.
