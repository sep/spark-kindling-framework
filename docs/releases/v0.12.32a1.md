# Release Notes - v0.12.32a1

Alpha release. Includes the CLI/entity introspection commands and health
checks staged since v0.12.31, plus a fix for `kindling entity tags`/
`kindling app validate`.

## Fixed

- **`kindling entity tags`/`kindling app validate` could fail with
  `KindlingNotInitializedError`**: both commands load `app.py` by executing
  it and only calling its `initialize()` afterward, so an `app.py` that
  imports an entity/pipe-registering module above its own `initialize()`
  definition fired that module's `@DataEntities.entity`/`@DataPipes.pipe`
  decorator before the framework was up. `_load_app_module` now retries
  once — pre-initializing the framework (using the same settings.yaml/
  settings.\<env\>.yaml discovery `kindling config show` already uses) and
  reloading — whenever the first attempt fails that way, matching the
  initialize-then-load order `kindling app run` already uses. Apps that
  already defer their registering imports inside `initialize()` succeed on
  the first attempt as before; `kindling config show` and `kindling
  pipeline run`/`migrate *` are unaffected.

## Added

- **New CLI config/entity/pipe introspection and health-check commands**:
  `kindling config show`/`kindling config diff`, `kindling entity list`,
  `kindling pipeline show`, `kindling entity tags`/`kindling pipeline show
  --tags`, `kindling app check`, and `kindling package check`. See
  `docs/proposals/kindling_cli_devex_gaps.md` and the full `Unreleased`
  history in `CHANGELOG.md` for details on everything staged since
  v0.12.31.
