# Release Notes - v0.12.6

Local Kindling app runs now accept the same just-in-time runtime configuration
overrides as remote app submissions.

## Standalone app run parameters

Use repeatable `--param KEY=VALUE` options with `kindling app run` when running
an app locally:

```bash
kindling app run orders \
  --param kindling.execution.parallel=true \
  --param kindling.execution.retries=3
```

Dotted keys build nested configuration, and values are coerced to their YAML
types. A YAML or JSON parameter file can also provide the base overrides:

```bash
kindling app run orders \
  --parameters params.yaml \
  --param kindling.execution.parallel=true
```

Repeatable `--param` values take precedence over values from `--parameters`.
The overrides are passed privately to the standalone runner and applied during
framework initialization, matching the configuration behavior of managed
platform submissions.

## Upgrade

```bash
kindling env update --version 0.12.6
```
