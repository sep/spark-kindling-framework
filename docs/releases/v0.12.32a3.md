# Release Notes - v0.12.32a3

Alpha release. Fixes `kindling package deploy`/`kindling package check` for
uv-based (PEP 621) packages.

## Fixed

- **`kindling package deploy`/`kindling package check` hardcoded
  `tool.poetry.name`/`version` and shelled out to `poetry build`**,
  breaking on any uv-based package -- a `[project]` (PEP 621) table with
  no `[tool.poetry]` section at all, the scaffolding convention since the
  poetry-to-uv migration. `_load_package_metadata` now reads `[project]`
  first, falling back to legacy `[tool.poetry]` for any package not yet
  converted. `_build_package_wheel` now runs `uv build wheel --out-dir`
  instead of `poetry build --format wheel --output`.
