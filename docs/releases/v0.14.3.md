# v0.14.3 — 0.14.2 on PyPI

0.14.3 publishes the 0.14.2 release to PyPI. It changes no code; read the
[0.14.2 notes](v0.14.2.md) for what's new since 0.14.1.

0.14.2 was released on GitHub but not on PyPI. The Cosmos DB and
OpenTelemetry Azure extensions kept version 0.14.0 although their packaging
had changed (the `uv_build` build requirement now allows `<0.14`), so their
rebuilt 0.14.0 files differed from the ones already on PyPI and the publish
was refused. They are now 0.14.1.

Package versions:

- Runtime, CLI, SDK: **0.14.3**.
- SDP and Databricks extensions: **0.14.2** (both require
  `spark-kindling>=0.14.1,<0.15`; Databricks also requires SDP 0.14.1 or
  later).
- Temporal, Cosmos DB and OpenTelemetry Azure extensions: **0.14.1**.
- ADX, Databricks Auto Loader and Visualization extensions: unchanged at
  **0.14.0**.

## Upgrading from 0.14.1

Follow the 0.14.2 upgrade notes. In short: move Fabric environments to
Runtime 2.0, and upgrade the Databricks extension together with the Temporal
extension (e.g. with `kindling env update`).

If you installed 0.14.2 from its GitHub release, 0.14.3 has the same code.
